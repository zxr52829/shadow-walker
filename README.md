# 影行者：双生回廊

一款基于 Pygame 开发的 2D 俯视角肉鸽地牢探险游戏。核心创意为影子分身机制——玩家可同时操控本体与影子两个独立单位，利用影子拉怪、探路、拾取道具，通过本体与影子的位置交换实现丰富的战术操作与解谜玩法。

## 游戏特色

### 核心创意玩法：双单位协同
- 影子召唤：释放可独立控制的影子分身，持续10-12秒，拥有独立碰撞体积
- 位置交换：瞬间与影子互换位置，配合无敌帧可完美规避伤害
- 影子回收：提前收回影子，大幅减少冷却时间
- 智能仇恨机制：敌人会优先攻击距离更近的影子单位

### 丰富的游戏系统
- 3个特色角色：旅者、刺客、守卫，各有独特被动技能
- 2大章节地牢：幽暗森林、晶簇矿洞，共25层随机生成地图
- 8种敌人类型：史莱姆、骷髅兵、暗影法师、精英骑士等
- 8种道具装备：消耗品、武器、护甲、饰品四大类
- 等级成长系统：击杀敌人获取经验，升级提升属性
- 永久升级树：收集晶核解锁永久属性加成
- 本地存档系统：自动保存进度，退出不丢失
- 随机关卡生成：每次地图完全随机，百玩不重样

## 操作说明

WASD：控制本体移动
方向键：控制影子移动
空格：召唤影子分身
E：与影子交换位置
Q：收回影子
J：普通攻击
1-6：使用对应物品栏道具
ESC：暂停/继续游戏
回车：菜单确认
R：结算界面返回主菜单

## 安装与运行

环境要求：Python 3.8+，Pygame 2.0+

安装依赖：pip install pygame
运行游戏：python main.py

## 项目结构

main.py：游戏主入口
requirements.txt：依赖声明
game/settings.py：全局配置数据
game/player.py：玩家与影子类
game/dungeon.py：随机地牢生成
game/enemy.py：敌人AI与战斗
game/items.py：道具实体
game/ui.py：界面渲染
